Browsers block reading pages from other sites (CORS), so an in-browser crawl has to go through a proxy that adds the missing header. Every URL and page you crawl passes through whoever runs that proxy — use one you trust or host your own. Must contain {url}. Leave empty to try a direct fetch, which only works on CORS-permissive sites.

Turn this on if a plain fetch returns near-empty pages — common for docs built with ReadMe, Docusaurus or similar.
